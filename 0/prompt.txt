  1. Where memories live and who sees them
  - Local by default. "Memories stay on your machine by default. A repository starts syncing only when you connect it to its hosted Entire repository: `entire brain connect`." After connecting, the background watcher syncs; `entire brain disconnect` stops it; `entire brain memories sync` syncs on demand. (https://docs.entire.com/guides/brain/overview.md)
  - Whether memories are committed to git is not stated. Only `.entire/agent-guide.md` and the AGENTS.md/CLAUDE.md references are described as files to "Review and commit ... to share the instructions with your team." (https://docs.entire.com/guides/brain/overview.md)
  - Security page (https://docs.entire.com/security.md) does not mention brain or memories at all. Its checkpoint-storage rules (refs/entire/checkpoints, shadow branches, redaction) are described for sessions/checkpoints, and it is unclear whether they apply to memories.
  - Entire-files page (https://docs.entire.com/guides/configuration/entire-files.md) does not mention brain or memory files.
  - Webhooks: `ENTIRE_BRAIN_WEBHOOK_URL` sends events on record/retract/refresh; memory text is excluded unless `ENTIRE_BRAIN_WEBHOOK_INCLUDE_TEXT=1`. `ENTIRE_BRAIN_NO_EGRESS` disables all webhooks and other network calls. (https://docs.entire.com/guides/brain/quickstart.md)
  
  2. Branch scoping and merge behavior
  - Not documented, except that the REST endpoint `GET /v1/facts` "Accepts `limit` and `branch`", implying memories carry a branch attribute (https://docs.entire.com/guides/brain/overview.md). No merge behavior is described.
  
  3. Trails
  - Trails page does not mention memory or brain at all (https://docs.entire.com/guides/trails/overview.md). No memory-to-trail link or attachment is documented.
  - A trail shows: linked changes (branches, across repos), each change's commits, checkpoints, and agent sessions; agent review results/findings; CI results; gates and approvals; diffs and a timeline. Findings block merge until resolved or dismissed (also in glossary: https://docs.entire.com/glossary.md).
  - Brain's relation to sessions/checkpoints: brain draws from "saved agent sessions, checkpoints, project memories, documentation, and code context" (https://docs.entire.com/guides/brain/overview.md). Memories can be extracted from past sessions during setup or by a session-end hook.
  
  4. Creation: `remember` vs automatic
  - Manual: `entire brain remember "<text>" --path <dotted.path>` (and `--global`). Quickstart: "Only save rules that are true for your project." (https://docs.entire.com/guides/brain/quickstart.md)
  - Automatic: `entire brain setup` "asks before it extracts memories from past sessions, and the default answer is no." Extraction "uses an available coding agent, can send session content to its model provider, and can add token charges." Background watcher and session-end hook "can call a coding agent to extract memories." (https://docs.entire.com/guides/brain/overview.md)
  - `distill`: not documented in any page I read. The overview's CLI examples use only overview, brief, query, remember, recall, status, doctor, viz, dash. Backfill is the closest documented automatic path.
  - `verify`: "Check whether saved memories still point to matching sources: `entire brain verify`." Hand-entered memories show `unverifiable-here`; verification checks references, not correctness. (https://docs.entire.com/guides/brain/quickstart.md)
  - `retract`: only documented as `memories retract` ("use `remember` and `memories retract` to change memories"), with no flags or details. (https://docs.entire.com/guides/brain/quickstart.md)
  - Other memory commands documented: `entire brain memories global`, `entire brain memories files --dir <dir>` (one Markdown file per memory, a read-only copy), `entire brain memories import --file <mem0 export> [--dry-run] [--path-prefix]` (default prefix `project.imported`), `entire brain memories sync`. `facts` was renamed to `memories`; `facts` still works as an alias. (https://docs.entire.com/guides/brain/overview.md, https://docs.entire.com/guides/brain/quickstart.md)
